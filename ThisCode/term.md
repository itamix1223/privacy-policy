# サービス概要

ThisCode（以下「本サービス」）は、チャット機能とボイスチャット機能を無料で提供するWebアプリおよびAndroid / iOSアプリです。運営者は、本利用規約（以下「本規約」）に基づき本サービスを提供します。

# 主な機能

- アカウント登録（メールアドレス確認、二要素認証）
- チャンネルでのチャット・投稿（添付ファイル、リアクション、メンション）
- フレンド機能とダイレクトメッセージ
- WebRTCを用いたボイスチャット（音声は録音・保存されません）
- プッシュ通知
- 日本語・英語・韓国語・中国語の表示
