# サービス概要

サービス名: ShallWeDrink
飲みログと興味のあるワードを記録し、近くで共通の話題を持つ利用者とのマッチングを支援するアプリです。基本機能は無料で利用できます。有料機能を提供する場合はiOS／Androidアプリ内で購入できます。

# 販売価格

- 有料機能の提供開始後、価格・課金期間は購入画面およびApple App Store／Google Playの各商品ページに税込価格で表示します。
- 表示価格以外に、インターネット接続に必要な通信料等は利用者の負担となります。

# 支払方法・支払時期

- 支払方法: Apple App StoreまたはGoogle Playが提供する決済方法
- 支払時期: 購入時に決済されます。自動更新の有料プランは、購入画面および各ストアの定める更新日に次回分が決済されます。

# サービス提供時期

有料機能の提供開始後は、決済完了後に購入した機能を利用できます。通信状況、審査、ストアまたは外部サービスの状況により、利用開始まで時間がかかる場合があります。

# 解約・返金

- 有料プランの解約および自動更新の停止は、購入したApple App StoreまたはGoogle Playのアカウント設定からお手続きください。アプリを削除しただけでは解約されません。
- 解約後も、購入済み期間の終了までは有料機能を利用できる場合があります。具体的な取扱いは購入したストアの条件に従います。
- デジタルサービスの性質上、法令またはストアの規約に定める場合を除き、決済完了後の返金・日割り精算は行いません。返金の申請は購入したストアの手続きに従ってください。
- 購入の復元は、購入したストアのアカウントでアプリ内の復元手続きを行ってください。

# 動作環境

Android、iOS、Webに対応しています。ただし、購入、文字認識、音声認識、位置情報、プッシュ通知等の機能は、利用する端末・OS・ブラウザおよび権限設定により利用できない場合があります。Web版ではアプリ内購入を利用できません。
