# サービス概要

「ShallWeDrink」は、飲酒記録を端末に保存し、近くで同じ話題を楽しみたい利用者とのマッチングを支援するアプリです。

# 取得する情報

- 飲みログ・マイワード: 店名、日時、金額、同行者、飲食・話題、満足度、酔い度、登録したワードなど。アプリ内の端末ストレージに保存され、サーバーへの同期・バックアップは行いません。
- 位置情報: 利用者が飲みログで「現在地を記録」した場合、そのログに位置情報を保存します。また、近隣探索を開始した場合、マッチングのために現在地の緯度・経度をFirebase Cloud Functionsへ送信します。探索中の位置情報とマイワードは近隣ユーザーの照合に使い、他の利用者に正確な位置を開示しません。マッチ結果には距離の目安と共通ワードが含まれます。
- 近隣探索情報: 匿名認証で作成したFirebaseユーザーID、位置情報、マイワード、探索の有効期限、通知トークンを、探索の実行と通知に利用します。探索情報は開始から15分で期限切れとなり、利用者が停止した場合は削除されます。
- 購入情報: 購入機能の提供開始後、RevenueCatおよびApple App Store／Google Playを通じた購入・復元の処理に必要な情報を取り扱います。アプリ内の飲みログやマイワードをFirebaseに保存することはありません。RevenueCatの購入イベントに基づくプレミアム利用状態はFirebaseに保存されます。
- 端末の権限・機能: 利用者が使う機能に応じて、位置情報、カメラ／写真ライブラリ、マイク、通知の各権限を利用します。音声認識の利用可否は端末・OS・ブラウザの対応状況に依存します。

# 情報の利用目的

- 飲みログとマイワードをアプリ内で表示・編集するため
- 同意を得て開始された近隣探索で、距離と共通ワードを照合し、マッチ通知を届けるため
- 店舗候補や地図を表示するため
- 購入状態を確認し、プレミアム機能を提供するため
- 問い合わせへの対応、不正利用の防止、サービスの維持・改善のため

# 端末内処理

- 飲みログとマイワードは端末内に保存されます。端末の故障、紛失、アプリの削除などにより失われる場合があります。
- レシート等の文字認識はAndroid／iOS端末上のGoogle ML Kitを使用します。認識結果はログ入力の補助に使い、認識対象の画像を当社サーバーへ送信しません。
- 音声認識は端末またはブラウザが提供する機能を利用します。認識処理や音声データの取扱いは、端末・ブラウザ提供者の仕様にも従います。

# 外部サービスへの提供・委託

機能の提供に必要な範囲で、以下のサービスを利用します。各事業者による情報の取扱いは、それぞれのプライバシーポリシーにも従います。

- Firebase Authentication、Cloud Functions、Firestore、Cloud Messaging: 匿名認証、近隣探索、プレミアム状態の管理、プッシュ通知
- Google Maps Platform／Google Places API: 地図表示、店舗候補の検索
- RevenueCat、Apple App Store、Google Play: アプリ内購入、購入状態の確認・復元
- Google ML Kit: Android／iOS端末上での文字認識

近隣探索を開始した場合、位置情報とマイワードは照合に必要な範囲でFirebaseへ送信されます。正確な位置情報や飲みログを他の利用者に公開しません。FirebaseのFirestoreはクライアントから直接読み書きできない設定とし、Cloud Functions経由で処理します。

# 保存期間・削除

- 近隣探索情報は開始から15分で有効期限切れとなり、期限経過後はマッチング対象外です。探索を停止した場合は、その時点でサーバー上の探索情報が削除されます。期限切れ情報の削除は、サーバーの定期削除処理に従います。
- 飲みログ・マイワードは端末内に保存され、利用者がアプリ内で削除するか、アプリのデータを削除するまで保持されます。
- 購入状態等のサーバー上の情報は、機能提供および法令上必要な期間保持します。アカウント関連情報の削除を希望する場合は、問い合わせ先までご連絡ください。

# 利用者の選択

位置情報、通知、カメラ、写真、マイクの権限は端末の設定から変更できます。近隣探索はアプリ内で開始し、探索中に停止できます。権限を許可しない場合、対応する機能を利用できないことがあります。
